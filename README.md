# PersonalFinancePlan

Система для построения персонального финансового плана: учёт транзакций
(доходов и расходов), аутентификация пользователей и клиентское
React-приложение. Курсовой проект, выполняется поэтапно в рамках
лабораторных работ.

## Структура репозитория

- Корень репозитория — серверная часть (REST API, Express + PostgreSQL).
- `client/` — клиентское React-приложение (Лабораторная работа 4),
  на данный момент автономное, работает через `localStorage` без
  обращения к серверу.

## Сервер

### Стек

- Node.js, Express.js
- PostgreSQL, Sequelize (миграции, сиды)
- JWT (jsonwebtoken), bcrypt — аутентификация

### Установка и запуск

Требуется установленный Node.js и локальный PostgreSQL.

    npm install

Создать файл `.env` в корне репозитория:

    DATABASE_URL=postgres://<user>:<password>@localhost:5432/finance_plan
    JWT_SECRET=<секретная строка>

Применить миграции и наполнить базу тестовыми данными:

    npm run db:migrate
    npm run db:seed

Запустить сервер:

    npm run dev

Сервер запустится на http://localhost:3000
`npm run dev` – запуск с автоперезапуском (nodemon); `npm start` – обычный запуск.

### Эндпоинты

**Транзакции**

| Метод  | Путь              | Назначение                    |
| ------ | ----------------- | ------------------------------ |
| GET    | /transactions     | список всех транзакций        |
| GET    | /transactions/:id | одна транзакция по id         |
| POST   | /transactions     | создать транзакцию            |
| PUT    | /transactions/:id | полностью обновить транзакцию |
| DELETE | /transactions/:id | удалить транзакцию            |

Фильтрация списка: `GET /transactions?type=income|expense` и/или `?category=<строка>`

Поля транзакции: `amount` (число > 0), `type` (income/expense), `category`
(строка), `date` (ГГГГ-ММ-ДД, необязательно), `description` (строка,
необязательно), `isRecurring` (bool, необязательно).

**Аутентификация**

| Метод | Путь                     | Назначение                          |
| ----- | ------------------------ | ------------------------------------ |
| POST  | /auth/register           | регистрация пользователя             |
| POST  | /auth/login               | вход, выдаёт JWT                    |
| GET   | /auth/verify-email/:token | подтверждение email                 |
| GET   | /profile                  | профиль текущего пользователя (JWT) |

Эндпоинты `/transactions` пока не защищены JWT — подключение авторизации
к ним запланировано на следующих этапах курсовой.

## Клиент (`client/`)

React-приложение на Vite, реализующее ту же предметную область
(транзакции) на клиенте. На данном этапе (ЛР4) полностью автономно и не
обращается к серверу — все данные хранятся в `localStorage` браузера.
В следующей лабораторной работе клиент будет подключён к REST API выше.

    cd client
    npm install
    npm run dev

Откроется на http://localhost:5173
